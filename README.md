# DropBeam 🚀

> Beam files directly between devices — no sign up, no limits.

DropBeam is a simple and privacy-focused peer-to-peer file sharing application that lets you transfer files directly between devices using WebRTC.

No account. No complicated setup. Just connect two devices and transfer your files.

## 🌐 Live Demo

👉 **Try DropBeam:**  
https://dropbeam-pearl.vercel.app/

## ✨ Features

- 🚀 Peer-to-peer file transfer
- 🔒 WebRTC-based communication
- 📁 Send multiple files
- 📂 Send folders
- 👤 No sign-up required
- ⚡ Fast device-to-device transfers
- 🌐 Works directly in the browser
- 📱 Mobile-friendly interface
- 🗄️ Files are not intended to be stored permanently on a central server
- ♾️ No application-level file size limit

## 🔐 Privacy First

DropBeam is designed with peer-to-peer file sharing in mind.

Files are transferred between connected devices using WebRTC instead of being uploaded to traditional cloud storage.

This means DropBeam does not need an account or a personal file-storage system.

> **Note:** WebRTC connections use encryption, but users should understand that the overall security and privacy of a web application depends on its complete implementation and deployment environment.

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Clone the repository

```bash
git clone https://github.com/dhanaseelan-a/dropbeam.git

Open the project
cd dropbeam

Install dependencies
npm install

Start the development server
npm run dev

Open the local URL provided by Vite in your browser.

📖 How It Works
Open DropBeam on two devices.
Choose Send on the device that has the files.
Choose Receive on the other device.
Establish the connection between the devices.
Select your files or folders.
Start the transfer.
Files are transferred between the connected devices.
